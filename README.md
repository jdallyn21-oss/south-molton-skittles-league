# South Molton Skittles League

Fixtures, results, and league tables for the South Molton Skittles League, 2026/27 season. Divisions 1, 2, and 3 are included. The site is view-only: one static `index.html` file with the layout and season data built in.

## Run locally

From this directory:

```bash
python3 -m http.server 47291 --bind 0.0.0.0
```

Open [http://127.0.0.1:47291](http://127.0.0.1:47291).
